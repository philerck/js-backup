Werte hinzufügen

In JavaScript-Arrays kann man neue Elemente an verschiedenen Stellen hinzufügen: am Ende, am Anfang oder an einer beliebigen Position im Array. Je nach Methode kann man Elemente einfach anhängen (push()), vorne einfügen (unshift()) oder flexibel an einer bestimmten Stelle einfügen, löschen oder ersetzen (splice()).

let teilnehmer = ["Roger Rabbit", "Teilnehmer 2", "Teilnehmer 3"];

push()

Fügt ein oder mehrere Elemente am Ende eines Arrays hinzu.

teilnehmer.push("Teilnehmer 4");
console.log(teilnehmer);

["Roger Rabbit", "Teilnehmer 2", "Teilnehmer 3", "Teilnehmer 4"]

unshift()

Fügt ein oder mehrere Elemente am Anfang eines Arrays hinzu.

teilnehmer.unshift("Teilnehmer 0");
console.log(teilnehmer);

["Teilnehmer 0", "Roger Rabbit", "Teilnehmer 2", "Teilnehmer 3", "Teilnehmer 4"]

splice()

Die splice()-Methode kann Elemente einfügen, entfernen oder ersetzen. Sie hat drei Parameter:

  1. Erster Parameter (start) – Index, ab dem eingefügt oder entfernt wird

  2. Zweiter Parameter (deleteCount) – Anzahl der zu löschenden Elemente

  3. Weitere Parameter (item1, item2, …) – Elemente, die eingefügt werden sollen

Erster Parameter: Startindex

// Index 2 auswählen – ab hier kann entfernt oder eingefügt werden
teilnehmer.splice(2, 0); // 0, damit nichts gelöscht wird
console.log(teilnehmer);

["Teilnehmer 0", "Roger Rabbit", "Teilnehmer 2", "Teilnehmer 3", "Teilnehmer 4"]

Zweiter Parameter: Anzahl der zu löschenden Elemente

// Ein Element ab Index 1 entfernen
teilnehmer.splice(1, 1);
console.log(teilnehmer);

["Teilnehmer 0", "Teilnehmer 2", "Teilnehmer 3","Teilnehmer 4"]

Weitere Parameter: Elemente einfügen

// Ab Index 1 ein neues Element einfügen, nichts löschen
teilnehmer.splice(1, 0, "Teilnehmer X");
console.log(teilnehmer);

["Teilnehmer 0", "Teilnehmer X", "Teilnehmer 2", "Teilnehmer 3","Teilnehmer 4"]

Kombination: Löschen und Einfügen

// Ab Index 2 ein Element ersetzen: ein Element löschen, ein neues einfügen
teilnehmer.splice(2, 1, "Teilnehmer Y");
console.log(teilnehmer);

["Teilnehmer 0", "Teilnehmer X", "Teilnehmer Y", "Teilnehmer 3", "Teilnehmer 4"]
