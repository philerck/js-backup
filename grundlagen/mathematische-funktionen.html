Mathe-Methoden

Das Math-Objekt in JavaScript ist eine Sammlung von Funktionen und Konstanten, die einem bei mathematischen Aufgaben helfen. Man muss es nicht selbst erstellen – es ist immer automatisch verfügbar.

Math.round()

Rundet eine Zahl auf die nächste ganze Zahl.

  • Alles ab .5 wird aufgerundet.

  • Alles darunter wird abgerundet.

console.log(Math.round(4.7)); 
console.log(Math.round(4.4));

5
4

Math.floor()

Rundet immer nach unten zur nächsten ganzen Zahl.

console.log(Math.floor(4.9)); 
console.log(Math.floor(4.1));

4
4

Math.ceil()

Rundet immer nach oben zur nächsten ganzen Zahl.

console.log(Math.ceil(4.1)); 
console.log(Math.ceil(4.9));

5
5

Math.trunc()

Schneidet die Nachkommastellen einfach ab, ohne zu runden.

console.log(Math.trunc(4.9)); 
console.log(Math.trunc(-4.9));

4
-4

Math.random()

Gibt eine Zufallszahl zwischen 0 (inklusive) und 1 (exklusive) zurück. 👉 Oft nutzt man sie mit Math.floor(), um Zufallszahlen in einem bestimmten Bereich zu erzeugen.

console.log(Math.random());  // z. B. 0.374
console.log(Math.floor(Math.random() * 6) + 1); // Würfel (1–6)

0.3745389218
3

Math.max() und Math.min()

  • Math.max() gibt die größte Zahl zurück.

  • Math.min() gibt die kleinste Zahl zurück.

console.log(Math.max(3, 7, 1, 9)); 
console.log(Math.min(3, 7, 1, 9));

9
1

Math.pow() und Math.sqrt()

  • Math.pow(a, b) = Zahl a hoch b.

  • Math.sqrt(x) = Quadratwurzel von x.

console.log(Math.pow(2, 3));  // 2³
console.log(Math.sqrt(16));

8
4

Math.abs()

Macht eine Zahl positiv (absoluter Wert).

console.log(Math.abs(-5)); 
console.log(Math.abs(5));

5
5

Math.sign()

Zeigt das Vorzeichen einer Zahl:

  • 1 für positive Zahlen

  • -1 für negative Zahlen

  • 0 wenn die Zahl genau 0 ist

console.log(Math.sign(-10)); 
console.log(Math.sign(0));
console.log(Math.sign(7));

-1
0
1

Math.sin() und Math.cos()

Sinus und Cosinus – nützlich für Winkelberechnungen, Animationen oder Spiele. 👉 Achtung: Winkel müssen im Bogenmaß (Radians) angegeben werden, nicht in Grad.

Umrechnung: Grad * (Math.PI / 180)

console.log(Math.sin(0)); // Sinus von 0°
console.log(Math.cos(Math.PI)); // Cosinus von 180°

0
-1

Math.random()`

In JavaScript gibt es keine eigene Funktion, die direkt eine Zufallszahl erzeugt. Stattdessen nutzt man die Methode Math.random() aus dem eingebauten Math-Objekt.

  • Math.random() erzeugt immer eine Zufallszahl zwischen 0 (inklusive) und 1 (exklusive). → Das bedeutet: Der kleinste mögliche Wert ist 0, der größte mögliche Wert ist knapp unter 1 (z. B. 0.999...), aber niemals genau 1.

  • Das Ergebnis ist eine Fließkommazahl (Dezimalzahl).

Um Zufallszahlen in anderen Bereichen zu erhalten (z. B. ganze Zahlen von 1 bis 10), kombiniert man Math.random() mit Multiplikation und Abrundungsfunktionen wie Math.floor().

Beispiele

1. Zufallszahl zwischen 0 und 1

let zahl = Math.random();
console.log(zahl); 

0.472834918

2. Zufallszahl zwischen 0 und 10 (ohne Ganzzahlen)

let zahl = Math.random() * 10;
console.log(zahl); 

7.3829182

3. Ganze Zufallszahl zwischen 0 und 9

let zahl = Math.floor(Math.random() * 10);
console.log(zahl); 

0, 1, 2, ..., 9

4. Ganze Zufallszahl zwischen 1 und 10

let zahl = Math.floor(Math.random() * 10) + 1;
console.log(zahl); 

1, 2, 3, ..., 10

5. Ganze Zufallszahl zwischen zwei beliebigen Grenzen (z. B. 5 und 15)

function zufallszahlZwischen(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

console.log(zufallszahlZwischen(5, 15)); 

5, 6, 7, ..., 15

Merke:

  • Math.random() alleine liefert nur Werte zwischen 0 und 1.

  • Durch Multiplikation wird der Bereich größer.

  • Mit Math.floor() (Abrunden) oder Math.ceil() (Aufrunden) erhält man ganze Zahlen.

  • Durch Verschieben mit + min lassen sich Werte in beliebige Bereiche legen.
