Schleifen

Beim Programmieren will man Aufgaben nicht mühsam händisch wiederholen. Stell dir vor, man müsste alle Zahlen von 0 bis 999 mit console.log() ausgeben – das wären 1000 Befehle, die man einzeln schreiben müsste. Das ist völlig unpraktisch.

Genau hier kommen Schleifen ins Spiel: Mit Schleifen kann man Code automatisch wiederholen lassen, solange bestimmte Bedingungen erfüllt sind. In JavaScript gibt es dafür verschiedene Varianten.

for-Schleife

Die for-Schleife ist besonders praktisch, wenn man genau weiß, wie oft etwas wiederholt werden soll.

Beispiel: Zahlen von 0 bis 9 ausgeben

for (let i = 0; i <= 9; i++) {
  console.log(i);
}

Aufbau der for-Schleife

for (Startwert; Bedingung; Schritt) {
  // Code, der wiederholt wird
}

  • Startwert: Wird einmalig ausgeführt, z. B. let i = 0;.

  • Bedingung: Vor jedem Durchlauf überprüft. Ist sie true, läuft die Schleife weiter. Ist sie false, wird die Schleife beendet.

  • Schritt: Nach jedem Durchlauf ausgeführt, meistens eine Erhöhung oder Verringerung (i++).

while-Schleife

Mit einer while-Schleife wiederholt man Code, solange die Bedingung erfüllt ist. Sie ist nützlich, wenn man nicht genau weiß, wie oft man den Code ausführen muss.

Aufbau der while-Schleife

while (Bedingung) {
  // Code, der wiederholt wird
}

  • Bedingung: Vor jedem Durchlauf wird die Bedingung geprüft.

    • Ist sie true, wird der Schleifen-Block ausgeführt.

    • Ist sie false, endet die Schleife sofort.

  • Code-Block: Alles, was innerhalb der geschweiften Klammern {} steht, wird bei jedem Durchlauf ausgeführt.

  • Änderung: Meistens verändert man innerhalb des Code-Blocks eine Variable (z. B. i++), damit die Bedingung irgendwann false wird.

Beispiel: Zahlen von 0 bis 9

let i = 0;
while (i <= 9) {
  console.log(i);
  i++;
}

do-while-Schleife

Die do-while-Schleife ist fast wie while, hat aber einen entscheidenden Unterschied: 👉 Der Code wird mindestens einmal ausgeführt, auch wenn die Bedingung von Anfang an false ist.

Aufbau der do-while-Schleife

do {
  // Code, der mindestens einmal ausgeführt wird
} while (Bedingung);

  • Code-Block: Alles in den geschweiften Klammern {} wird immer einmal ausgeführt.

  • Bedingung: Erst nach dem Code-Block wird die Bedingung geprüft.

    • Ist sie true, startet ein neuer Durchlauf.

    • Ist sie false, endet die Schleife.

Beispiel 1: Zahlen von 0 bis 9

let i = 0;
do {
  console.log(i);
  i++;
} while (i <= 9);

Aufbau

Besonderheit

Typischer Einsatz

for

for (Startwert; Bedingung; Schritt) { ... }

Alle drei Teile (Start, Bedingung, Schritt) stehen direkt in der Kopfzeile.

Wenn man vorher weiß, wie oft die Schleife laufen soll. Beispiel: von 0 bis 100 zählen.

while

while (Bedingung) { ... }

Bedingung wird vor jedem Durchlauf geprüft.

Wenn man nicht genau weiß, wie oft wiederholt werden muss. Beispiel: Eingaben prüfen, bis sie gültig sind.

do-while

do { ... } while (Bedingung);

Code wird mindestens einmal ausgeführt, Bedingung erst danach geprüft.

Wenn etwas garantiert mindestens einmal passieren soll. Beispiel: Nutzer mindestens einmal zur Eingabe auffordern.
