Bedingungen

Normalerweise wird Programmcode in JavaScript Zeile für Zeile von oben nach unten ausgeführt. Oft möchte man aber, dass bestimmte Anweisungen nur dann ausgeführt werden, wenn eine Bedingung erfüllt ist.
Solche Entscheidungen, die den Kontrollfluss eines Programms beeinflussen, nennt man bedingte Anweisungen.

Die if-Anweisung

Eine if-Anweisung prüft eine Bedingung und führt den zugehörigen Codeblock nur dann aus, wenn die Bedingung true ergibt.

          %%{init: {"theme": "neutral"}}%%
  graph LR
    A([Start]) --> b{alter >= 18}
    b -- true --> c("console.log('Du darfst Auto<br> fahren')")
    b -- false --> d((Ende))
    c --> d([Ende])
    
if (bedingung) {
  // Code, der ausgeführt wird, wenn die Bedingung true ist
}

let alter = 18;

if (alter >= 18) {
  console.log("Sie dürfen Auto fahren in Deutschland");
}

Sie dürfen Auto fahren in Deutschland

Erklärung:

  • In den runden Klammern () steht die Bedingung: alter >= 18.

  • Die Bedingung wird zu einem Booleschen Wert (true oder false) ausgewertet.

  • Ist die Bedingung true, wird der Codeblock innerhalb der geschweiften Klammern {} ausgeführt.

  • Ist sie false, wird der Code übersprungen.

Lesart: „Wenn das Alter mindestens 18 ist, dann gib diesen Text auf der Konsole aus.“

Vergleich mit ===

let color = "red";

if (color === "red") {
  color = "blue";
  console.log(color);
}

console.log(color);

blue
blue

  • === prüft, ob Wert und Datentyp übereinstimmen.

  • Da color "red" ist, ergibt die Bedingung true.

  • Der Code im if-Block wird ausgeführt und ändert color auf "blue".

  • Nach dem if-Block wird der neue Wert "blue" wieder ausgegeben.

Die if-else-Anweisung

Ein else-Block wird ausgeführt, wenn die if-Bedingung nicht erfüllt ist:

          %%{init: {"theme": "neutral"}}%%
  graph LR
    A([Start]) --> b{alter >= 18}
    b -- true --> c("console.log('Du darfst Auto<br> fahren')") --> d([Ende])
    b -- false --> c2("console.log('Du darfst kein<br> Auto fahren')") --> d([Ende])
    
let alter = 16;

if (alter >= 18) {
  console.log("Sie dürfen Auto fahren in Deutschland");
} else {
  console.log("Sie dürfen kein Auto fahren in Deutschland");
}

Sie dürfen kein Auto fahren in Deutschland

Lesart: „Wenn das Alter mindestens 18 ist, dann Ausgabe A, sonst Ausgabe B.“

Mehrere Bedingungen: if – else if – else

Mit else if können mehrere Bedingungen hintereinander geprüft werden:

          %%{init: {"theme": "neutral",
  "themeVariables": {"fontSize": "16px"},
  "flowchart": { "nodeSpacing": 125, "rankSpacing": 25 }
}}%%
  graph TB
    A([Start]) --> b1{alter >= 18}
    b1 -- true --> a1(FSK18, FSK16,<br> FSK12, FSK6) --> e([Ende])
    b1 -- false --> b2{alter >= 16} -- true --> a2(FSK16, FSK12, FSK6) --> e([Ende])
    b2 -- false --> b3{alter >= 12} -- true --> a3(FSK12, FSK6) --> e([Ende])
    b3 -- false --> b4{alter >= 6} -- true --> a4(FSK6) --> e([Ende])
    b4 -- false --> a5(Keine Filme<br>freigegeben) --> e([Ende])
    
let alter = 16;

if (alter >= 18) {
  console.log("FSK18, FSK16, FSK12, FSK6");
} else if (alter >= 16) {
  console.log("FSK16, FSK12, FSK6");
} else if (alter >= 12) {
  console.log("FSK12, FSK6");
} else if (alter >= 6) {
  console.log("FSK6");
} else {
  console.log("Keine Filme freigegeben");
}

FSK16, FSK12, FSK6

  • Die erste Bedingung, die true ergibt, bestimmt den ausgeführten Block.

  • Alle weiteren Bedingungen werden nicht mehr geprüft.

Logische Operatoren in Bedingungen

Oft möchte man mehrere Bedingungen kombinieren oder eine Bedingung umkehren. Dafür gibt es logische Operatoren:

Operator

Bedeutung

Beispiel

Ergebnis

&&

UND – beide Bedingungen müssen true sein

(alter >= 18 && wohnort === "Deutschland")

true, wenn beide Bedingungen erfüllt sind

||

ODER – eine oder beide Bedingungen müssen true sein

(alter >= 18 || wohnort === "Deutschland")

true, wenn eine oder beide Bedingungen erfüllt sind

!

NICHT – kehrt den Wert um

!(alter >= 18)

true, wenn die Bedingung nicht erfüllt ist

UND (&&)

let alter = 20;
let wohnort = "Deutschland";

if (alter >= 18 && wohnort === "Deutschland") {
  console.log("Sie dürfen in Deutschland Auto fahren");
}

Sie dürfen in Deutschland Auto fahren

ODER (||)

let farbe = "blau";

if (farbe === "rot" || farbe === "blau") {
  console.log("Die Farbe ist entweder rot oder blau");
}

Die Farbe ist entweder rot oder blau

NICHT (!)

let ticket = false;

if (!ticket) {
  console.log("Sie haben kein Ticket");
}

Sie haben kein Ticket

Der ternäre Operator ? :

Für einfache if-else-Entscheidungen kann man den ternären Operator nutzen.

bedingung ? wertWennTrue : wertWennFalse;

let alter = 18;
let nachricht =
  alter >= 18 ? "Sie sind volljährig" : "Sie sind nicht volljährig";

console.log(nachricht);

Sie sind volljährig

  • alter >= 18 wird geprüft.

  • Ist die Bedingung true, wird "Sie sind volljährig" zurückgegeben.

  • Ist die Bedingung false, wird "Sie sind nicht volljährig" zurückgegeben.

  • Das Ergebnis wird in nachricht gespeichert und ausgegeben.

Hinweis: Der ternäre Operator ist ideal für kurze Bedingungen, sollte aber nicht zu verschachtelt werden, damit der Code lesbar bleibt.
