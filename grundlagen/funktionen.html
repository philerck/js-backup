Funktionen

Was sind Funktionen?

Funktionen sind wiederverwendbare Codeblöcke, die eine bestimmte Aufgabe ausführen. Man kann sie sich wie kleine Maschinen vorstellen: man gibt ihnen Daten (Parameter), sie verarbeiten diese Daten und liefern optional ein Ergebnis zurück. Funktionen helfen uns, Code sauber, übersichtlich und wiederverwendbar zu halten.

Beispiel:

function sagHallo(name) {
  console.log("Hallo " + name + "!");
}

sagHallo("Anna"); // Ausgabe: Hallo Anna!
sagHallo("Ben");  // Ausgabe: Hallo Ben!

Function Declaration (Funktionsdeklaration)

Die klassische Art, eine Funktion zu erstellen, ist die Function Declaration. Diese Art ist einfach zu verstehen und wird häufig verwendet.

Aufbau: function + Funktionsname + () + {}

function sagHallo(name) {  // "name" ist der Parameter
  console.log("Hallo " + name + "!");
}

Erklärung der Teile:

  • function = Schlüsselwort, das JavaScript sagt: „Hier kommt eine Funktion“

  • sagHallo = Name der Funktion (frei wählbar)

  • (name) = Klammern mit Parametern (hier: ein Parameter namens „name“)

  • {} = Geschweifte Klammern mit dem Code, der ausgeführt wird

Funktionsaufrufe:

sagHallo("Anna"); // "Anna" ist der Wert für den Parameter
sagHallo("Ben");  // "Ben" ist der Wert für den Parameter

Funktionsaufruf: Eine Funktion wird ausgeführt, indem man ihren Namen schreibt und Klammern () anhängt. In die Klammern schreibt man die Werte, die die Funktion verwenden soll.

Besonderheit: Function Declarations können bereits vor ihrer Definition im Code aufgerufen werden. Das bedeutet, du kannst die Funktion verwenden, bevor sie im Code steht:

// Funktionsaufruf vor der Definition - funktioniert!
console.log(addiere(2, 3)); // Ausgabe: 5

function addiere(a, b) {
  return a + b;
}

Parameter

Parameter sind Platzhalter für die Daten, die man der Funktion gibt. Beim Aufruf werden die Parameter durch konkrete Werte ersetzt.

Beispiel mit Erklärung:

function addiere(a, b) {  // "a" und "b" sind Parameter (Platzhalter)
  return a + b;
}

console.log(addiere(5, 3)); // 5 ersetzt "a", 3 ersetzt "b" → Ausgabe: 8

Wichtige Punkte:

  • Die Reihenfolge der Parameter muss eingehalten werden

  • Funktionen können auch ohne Parameter aufgerufen werden, wenn sie keine benötigen

Weitere Beispiele:

function hallo(vorname, nachname) {  // zwei Parameter
  return `Hallo ${vorname} ${nachname}`;
}

console.log(hallo("Anna", "Schmidt")); // Ausgabe: Hallo Anna Schmidt
console.log(hallo("Schmidt", "Anna")); // Ausgabe: Hallo Schmidt Anna (falsche Reihenfolge!)

function zufallszahl() {  // keine Parameter
  return Math.random();
}

console.log(zufallszahl()); // Aufruf ohne Werte in den Klammern

Return - Rückgabewerte

Mit return kann eine Funktion ein Ergebnis zurückgeben. Das Ergebnis kann dann weiterverwendet werden.

Beispiel:

function multipliziere(a, b) {
  return a * b;  // Gibt das Ergebnis zurück
}

let ergebnis = multipliziere(4, 5);  // ergebnis enthält jetzt 20
console.log(ergebnis);  // Ausgabe: 20

// Oder direkt verwenden:
console.log(multipliziere(3, 7));  // Ausgabe: 21

Unterschied zwischen return und console.log:

// Mit return - Wert wird zurückgegeben
function addiereMitReturn(a, b) {
  return a + b;
}

// Mit console.log - nur Ausgabe, kein Rückgabewert
function addiereMitLog(a, b) {
  console.log(a + b);
}

let wert1 = addiereMitReturn(5, 3);  // wert1 = 8
let wert2 = addiereMitLog(5, 3);     // wert2 = undefined (nichts zurückgegeben)

console.log(wert1);  // Ausgabe: 8
console.log(wert2);  // Ausgabe: undefined

Wichtig: Nach return wird die Funktion beendet. Code nach return wird nicht mehr ausgeführt:

function beispiel() {
  console.log("Das wird ausgeführt");
  return "Fertig!";
  console.log("Das wird NICHT ausgeführt");  // Wird nie erreicht
}

Default Parameter (Standardwerte)

Funktionen können Standardwerte für Parameter haben. Diese werden verwendet, wenn beim Aufruf kein Wert übergeben wird.

Beispiel:

function begruesse(name = "Gast") {
  return `Hallo ${name}!`;
}

console.log(begruesse("Anna"));  // Ausgabe: Hallo Anna!
console.log(begruesse());        // Ausgabe: Hallo Gast! (Standardwert wird verwendet)

function berechnePreis(menge, einzelpreis = 10) {
  return menge * einzelpreis;
}

console.log(berechnePreis(3, 15));  // Ausgabe: 45 (3 * 15)
console.log(berechnePreis(5));      // Ausgabe: 50 (5 * 10, Standardwert für einzelpreis)

Vorteil: Default Parameter machen Funktionen flexibler und verhindern Fehler, wenn vergessen wird, alle Parameter zu übergeben.

Anonyme Funktionen

Eine anonyme Funktion ist eine Funktion ohne eigenen Namen. Man verwendet sie dort, wo eine Funktion direkt gebraucht wird – zum Beispiel als Wert in einer Variablen oder als Argument für eine andere Funktion.

Beispiel – in einer Variablen gespeichert:

const multipliziere = function(a, b) {
  return a * b;
};

console.log(multipliziere(3, 4)); // Ausgabe: 12

function(a, b) { ... } ist hier anonym – sie hat keinen eigenen Namen, sondern wird in der Variablen multipliziere gespeichert.

Beispiel – direkt als Argument:

setTimeout(function() {
  console.log("Nach 2 Sekunden!");
}, 2000);

Die anonyme Funktion wird hier sofort an setTimeout übergeben und nach 2 Sekunden ausgeführt.

Wichtig zu wissen:

  • Viele Function Expressions sind anonyme Funktionen

  • Arrow Functions sind immer anonym

Function Expression (Funktionsausdruck)

Hier wird die Funktion einer Variablen zugewiesen. Sie muss vor der Nutzung definiert sein.

Aufbau: Variable + = + function + () + {}

const multipliziere = function(a, b) {
  return a * b;
};

console.log(multipliziere(4, 6)); // Ausgabe: 24

Erklärung der Teile:

  • const multipliziere = Variable, die die Funktion speichert

  • = = Zuweisungsoperator

  • function(a, b) = Anonyme Funktion (ohne eigenen Namen) mit Parametern

  • {} = Code der Funktion

  • ; = Semikolon am Ende (weil es eine Variablenzuweisung ist)

Wichtig: Bei Function Expressions muss die Funktion zuerst definiert werden, bevor sie aufgerufen werden kann:

// Das funktioniert NICHT:
console.log(multipliziere(2, 3)); // Fehler!

const multipliziere = function(a, b) {
  return a * b;
};

Arrow Function (Pfeilfunktion)

Moderne, kompakte Schreibweise für Funktionen. Besonders praktisch bei kurzen Funktionen.

Aufbau: Variable + = + Parameter + => + Rückgabewert/Code

const quadriere = (x) => x * x;

console.log(quadriere(5)); // Ausgabe: 25

Erklärung der Teile:

  • const quadriere = Variable, die die Funktion speichert

  • = = Zuweisungsoperator

  • (x) = Parameter in Klammern

  • => = Pfeil-Symbol (daher „Arrow Function“)

  • x * x = Code, der ausgeführt wird (bei kurzen Funktionen automatisch return)

Längere Arrow Function mit geschweiften Klammern:

const begruesse = (name) => {
  return `Hallo ${name}, schön dich zu sehen!`;
};

console.log(begruesse("Lisa")); // Ausgabe: Hallo Lisa, schön dich zu sehen!

Bei längeren Funktionen: {} verwenden und return explizit schreiben.

Warum gibt es unterschiedliche Arten und wann verwendet man was?

Function Declaration

Wann verwenden:

  • Wenn die Funktion überall im Code verfügbar sein soll

  • Für Hauptfunktionen des Programms

Beispiel:

function berechnePreis(menge, einzelpreis) {
  return menge * einzelpreis;
}

Function Expression

Wann verwenden:

  • Wenn die Funktion nur nach ihrer Definition verwendet werden soll

  • Für bedingte Funktionserstellung

  • Wenn Funktionen als Werte behandelt werden sollen

Beispiel:

let rabattFunktion;
if (kunde === "premium") {
  rabattFunktion = function(preis) {
    return preis * 0.8;  // 20% Rabatt
  };
} else {
  rabattFunktion = function(preis) {
    return preis * 0.95;  // 5% Rabatt
  };
}

let neuerPreis = rabattFunktion(100);  // Funktionsaufruf mit Parameter 100
console.log(neuerPreis);               // Ausgabe: 80 oder 95 (je nach kunde)

Arrow Function

Wann verwenden:

  • Für kurze, einfache Funktionen

  • Bei Array-Methoden wie map, filter, forEach

  • Wenn kompakter Code gewünscht ist

Beispiel:

const zahlen = [1, 2, 3, 4, 5];
const doppelt = zahlen.map(x => x * 2);  // [2, 4, 6, 8, 10]
