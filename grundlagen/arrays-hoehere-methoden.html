map, filter, reduce

Arrays bieten in JavaScript viele praktische Methoden, mit denen man Daten verändern, auswählen oder zusammenfassen kann. Besonders wichtig sind dabei die Methoden map, filter und reduce. Sie machen es möglich, auf einfache und elegante Weise mit Arrays zu arbeiten.

Wichtige Hinweise vorab:

  • Diese Methoden erwarten eine Funktion als Argument (eine Callback-Funktion). Man gibt die Funktion als Referenz weiter — also ohne Klammern: array.map(double) und nicht array.map(double()).

  • Häufig verwendet man anonyme Funktionen oder Arrow-Funktionen: array.map(x => x * 2); man kann aber auch normale Funktionsdeklarationen verwenden: function double(x){ return x*2 }.

  • Resultate speichert man in const oder let, z. B. const neu = arr.map(...), damit man später darauf zugreifen kann.

  • map und filter erzeugen neue Arrays; sie verändern das Ursprungsarray nicht. reduce liefert einen einzelnen Wert (kann aber auch ein Objekt oder Array sein).

map — jedes Element umwandeln

map nimmt ein Array und wendet auf jedes Element dieselbe Funktion an. Ergebnis ist ein neues Array mit der gleichen Länge wie das Original.

Syntax (vereinfacht):

const neu = arr.map((element, index, array) => { /* return neuerWert */ });

Beispiele:

  1. Zahlen verdoppeln

const zahlen = [1, 2, 3, 4];
const verdoppelt = zahlen.map(n => n * 2);
console.log(verdoppelt); // [2, 4, 6, 8]

  1. Mit Named Function

function square(x) { return x * x; }
const quadriert = zahlen.map(square);
console.log(quadriert); // [1, 4, 9, 16]

  1. Index verwenden

const arr = [10, 20, 30];
const mitIndex = arr.map((value, i) => value + i);
console.log(mitIndex); // [10, 21, 32]

  1. Aus Objekten ein neues Array bauen

const schueler = [
  {name: 'Anna', alter: 15},
  {name: 'Ben', alter: 16}
];
const namen = schueler.map(s => s.name);
console.log(namen); // ['Anna', 'Ben']

  1. Mapping zu neuen Objekten

const mitBegruessung = schueler.map(s => ({ text: `Hallo ${s.name}`, alter: s.alter }));
console.log(mitBegruessung);
// [{text: 'Hallo Anna', alter:15}, {text: 'Hallo Ben', alter:16}]

filter — Elemente auswählen

filter läuft über alle Elemente und behält nur die, für die die Callback-Funktion true zurückgibt. Ergebnis: ein neues Array mit höchstens so vielen Elementen wie das Original.

Syntax (vereinfacht):

const gefiltert = arr.filter((element, index, array) => /* true oder false */);

Beispiele:

  1. Gerade Zahlen filtern

const zahlen = [1, 2, 3, 4, 5, 6];
const gerade = zahlen.filter(n => n % 2 === 0);
console.log(gerade); // [2,4,6]

  1. Strings nach Länge filtern

const worte = ['Haus', 'Baum', 'a', 'Schule'];
const kurz = worte.filter(w => w.length <= 4);
console.log(kurz); // ['Haus','Baum','a']

  1. Objekte filtern

const personen = [
  {name:'Clara', punkte: 85},
  {name:'Dirk', punkte: 42},
  {name:'Eva', punkte: 77}
];
const bestanden = personen.filter(p => p.punkte >= 60);
console.log(bestanden); // [{name:'Clara',...}, {name:'Eva',...}]

  1. Kombinieren mit map

const namenBestanden = personen
  .filter(p => p.punkte >= 60)
  .map(p => p.name);
console.log(namenBestanden); // ['Clara','Eva']

reduce — aus einem Array einen einzelnen Wert machen

reduce „reduziert“ ein Array auf einen einzigen Rückgabewert. Diese Methode ist sehr mächtig: sie kann Summen, Produkte, Objekte, Arrays oder komplexe Strukturen erzeugen.

Syntax (vereinfacht):

const ergebnis = arr.reduce((accumulator, currentValue, index, array) => {
  return /* neuer accumulator */;
}, initialValue);

Einfache Beispiele:

  1. Summe berechnen

const zahlen = [1, 2, 3, 4];
const summe = zahlen.reduce((acc, cur) => acc + cur, 0);
console.log(summe); // 10

  1. Produkt aller Zahlen

const produkt = zahlen.reduce((acc, cur) => acc * cur, 1);
console.log(produkt); // 24

  1. Maximum finden

const max = zahlen.reduce((acc, cur) => Math.max(acc, cur), -Infinity);
console.log(max); // 4

Komplexere Anwendungsfälle:

  1. Häufigkeiten zählen

const farben = ['rot', 'blau', 'rot', 'grün', 'blau', 'rot'];
const zaehler = farben.reduce((acc, farbe) => {
  acc[farbe] = (acc[farbe] || 0) + 1;
  return acc;
}, {});
console.log(zaehler); // { rot: 3, blau: 2, grün: 1 }

  1. Array flach machen (flatten)

const nested = [[1,2], [3,4], [5]];
const flach = nested.reduce((acc, arr) => acc.concat(arr), []);
console.log(flach); // [1,2,3,4,5]

  1. Array von Objekten in ein Objekt umwandeln

const users = [
  {id: 'u1', name: 'Mia'},
  {id: 'u2', name: 'Jan'}
];
const byId = users.reduce((acc, user) => {
  acc[user.id] = user;
  return acc;
}, {});
console.log(byId);
// { u1: {id:'u1',name:'Mia'}, u2: {id:'u2',name:'Jan'} }

  1. Durchschnitt berechnen

const zahlen2 = [10, 20, 30];
const avg = zahlen2.reduce((a,b)=>a+b, 0) / zahlen2.length;
console.log(avg); // 20

  1. Gesamter Preis für Produkte in einer Kategorie

const warenkorb = [
  {name: 'Tasse', preis: 5, kategorie: 'Haushalt'},
  {name: 'Buch', preis: 12, kategorie: 'Medien'},
  {name: 'Teller', preis: 8, kategorie: 'Haushalt'}
];
const gesamtHaushalt = warenkorb
  .filter(p => p.kategorie === 'Haushalt')
  .reduce((acc, p) => acc + p.preis, 0);
console.log(gesamtHaushalt); // 13
