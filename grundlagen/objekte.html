Objekte in JavaScript

Was sind Objekte?

Objekte sind Sammlungen von Daten, die zusammengehören. Man kann sich ein Objekt wie eine Schublade mit Fächern vorstellen: jedes Fach hat einen Namen (Schlüssel) und einen Inhalt (Wert).

Beispiel:

const person = {
  name: "Max",
  age: 30,
  isStudent: false
};

Ein Objekt erstellen

Man schreibt ein Objekt mit { } und gibt darin Schlüssel-Wert-Paare an. Jeder Schlüssel beschreibt eine Eigenschaft, jeder Wert den Inhalt.

const book = {
  title: "JavaScript für Anfänger",
  author: "Anna Schmidt",
  year: 2023
};

Auf Eigenschaften zugreifen

Um auf die Werte eines Objekts zuzugreifen, benutzt man Punkt-Notation oder Klammer-Notation.

console.log(book.title);    // "JavaScript für Anfänger"
console.log(book["author"]); // "Anna Schmidt"

Klammer-Notation wird verwendet, wenn der Schlüssel aus mehreren Wörtern besteht.

Eigenschaften ändern oder hinzufügen

Objekte sind veränderbar. Man kann bestehende Eigenschaften ändern oder neue hinzufügen.

book.year = 2024;        // Wert ändern
book.pages = 350;        // Neues Fach hinzufügen

Methoden – Funktionen in Objekten

Objekte können Funktionen enthalten, die Aktionen ausführen. Diese nennt man Methoden.

const person = {
  name: "Mia",
  greet: function() {
    console.log("Hallo, ich bin " + this.name);
  }
};

person.greet(); // Hallo, ich bin Mia

this – Das eigene Objekt

  • this ist ein Platzhalter für das aktuelle Objekt, das die Methode aufruft.

  • Dadurch können Methoden auf die eigenen Eigenschaften des Objekts zugreifen.

  • Vorteil: Man kann denselben Code in verschiedenen Objekten verwenden, ohne den Namen jedes Mal fest eintragen zu müssen.

Beispiel:

const hund = {
  name: "Bello",
  bellen() {
    console.log(this.name + " sagt: Wuff!");
  }
};

hund.bellen();  // Bello sagt: Wuff!

Hier steht this.name für hund.name. Ruft ein anderes Objekt dieselbe Methode auf, bezieht sich this automatisch auf dieses andere Objekt.

Methode in mehreren Objekten

Man kann eine Funktion einmal definieren und sie dann in mehreren Objekten als Methode verwenden. this bezieht sich dabei immer auf das Objekt, das die Methode aufruft.

function vorstellen() {
  console.log("Hallo, ich bin " + this.name);
}

const person1 = {
  name: "Anna",
  greet: vorstellen
};

const person2 = {
  name: "Ben",
  greet: vorstellen
};

person1.greet(); // Hallo, ich bin Anna
person2.greet(); // Hallo, ich bin Ben

Obwohl beide Objekte dieselbe Funktion vorstellen nutzen, zeigt this auf das jeweilige Objekt, das die Methode aufruft.

Methode kopieren

Man kann eine Methode auch direkt von einem Objekt ins andere übertragen.

const hund = {
  name: "Bello",
  bellen() {
    console.log(this.name + " sagt: Wuff!");
  }
};

const katze = {
  name: "Minka"
};

// Methode von hund in katze übernehmen
katze.machenLaut = hund.bellen;

hund.bellen();   // Bello sagt: Wuff!
katze.machenLaut(); // Minka sagt: Wuff!

Hier wird derselbe Code benutzt, aber this passt sich automatisch an und zeigt beim Aufruf durch katze auf das Objekt katze.

Szenario: Mehrere Produkte im Online-Shop

Man hat mehrere Produkte (z. B. in einem Shop). Jedes Produkt soll eine Methode haben, die den Preis mit Mehrwertsteuer berechnet.

Anstatt die Funktion in jedem Objekt neu zu schreiben, erstellt man sie einmal und hängt sie an alle Produkte.

// Funktion, die den Preis mit MwSt. berechnet
function mitMwst() {
  return this.preis * 1.19;  // this.preis = Preis des aktuellen Produkts
}

// Mehrere Produkt-Objekte
const produkt1 = {
  name: "Laptop",
  preis: 1000,
  getPreisMitMwst: mitMwst
};

const produkt2 = {
  name: "Handy",
  preis: 500,
  getPreisMitMwst: mitMwst
};

const produkt3 = {
  name: "Tablet",
  preis: 300,
  getPreisMitMwst: mitMwst
};

// Methoden aufrufen
console.log(produkt1.name + ": " + produkt1.getPreisMitMwst() + " €");
// Laptop: 1190 €
console.log(produkt2.name + ": " + produkt2.getPreisMitMwst() + " €");
// Handy: 595 €
console.log(produkt3.name + ": " + produkt3.getPreisMitMwst() + " €");
// Tablet: 357 €

Erklärung

  • Jedes Produkt ist ein eigenes Objekt.

  • Alle nutzen dieselbe Funktion mitMwst, die mithilfe von this.preis den passenden Wert aus dem jeweiligen Objekt nimmt.

  • Vorteil: Man muss die Berechnungslogik nur einmal schreiben, aber für beliebig viele Objekte verwenden.

Object.keys, Object.values, Object.entries

Mit diesen Methoden kann man alle Eigenschaften oder Werte eines Objekts auf einen Blick sehen.

  • Object.keys(obj) → alle Schlüssel (als Array)

  • Object.values(obj) → alle Werte (als Array)

  • Object.entries(obj) → alle Schlüssel-Wert-Paare (als Array von Arrays)

Beispiele (einfacher Zugriff):

console.log(Object.keys(book));    
// ["title", "author", "year"]

console.log(Object.values(book));  
// ["JavaScript für Anfänger", "Anna Schmidt", 2024]

console.log(Object.entries(book)); 
// [["title", "JavaScript für Anfänger"], ["author", "Anna Schmidt"], ["year", 2024]]

Verwendung in Schleifen

Da die Methoden Arrays zurückgeben, kann man mit einer Schleife über sie iterieren:

Alle Schlüssel durchlaufen:

for (const key of Object.keys(book)) {
  console.log("Schlüssel:", key);
}
// Schlüssel: title
// Schlüssel: author
// Schlüssel: year

Alle Werte durchlaufen:

for (const value of Object.values(book)) {
  console.log("Wert:", value);
}
// Wert: JavaScript für Anfänger
// Wert: Anna Schmidt
// Wert: 2024

Alle Schlüssel-Wert-Paare durchlaufen:

for (const [key, value] of Object.entries(book)) {
  console.log(key + " → " + value);
}
// title → JavaScript für Anfänger
// author → Anna Schmidt
// year → 2024

Wann benutzt man Objekte?

Objekte sind praktisch, wenn man zusammenhängende Daten speichern oder Daten mit Methoden verbinden will.

  • Beispiele: Person, Auto, Buch

  • Vorteil: übersichtliche Struktur
