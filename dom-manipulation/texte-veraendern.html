Texte verändern

Wenn man mit JavaScript arbeitet, möchte man häufig den Text oder Inhalt eines HTML-Elements verändern – etwa eine Begrüßung, eine Nachricht oder eine Beschreibung auf der Webseite.

Dafür gibt es zwei besonders wichtige Eigenschaften:

  • .textContent – wenn man nur Text (ohne HTML) einfügen oder auslesen möchte.

  • .innerHTML – wenn man HTML-Strukturen (z. B. Überschriften, Formatierungen oder Listen) mit einfügen will.

Beide verändern den Inhalt eines Elements, aber auf unterschiedliche Weise.

textContent

Die Eigenschaft .textContent liest oder ändert den gesamten Text eines Elements, unabhängig davon, ob der Text sichtbar oder versteckt ist. HTML-Tags werden nicht interpretiert, sondern als einfacher Text behandelt.

Wann man .textContent verwenden sollte:

  • Wenn man nur reinen Text einfügen möchte.

  • Wenn keine HTML-Formatierungen benötigt werden.

  • Wenn der Inhalt sicher sein soll, zum Beispiel wenn Texte aus Eingaben oder externen Daten stammen.

HTML:

<p id="text2">Hallo Welt!</p>
<button id="btn2">Text ändern</button>

JavaScript:

const p2 = document.querySelector("#text2");
const button2 = document.querySelector("#btn2");

button2.addEventListener("click", () => {
    p2.textContent = "Hallo JavaScript!";
});

Erklärung: Beim Klick auf den Button wird der gesamte Inhalt des <p>-Elements ersetzt. Selbst wenn man HTML-Tags in den neuen Text schreibt, werden diese nicht als HTML erkannt, sondern als normaler Text angezeigt.

Beispiel:

p2.textContent = "<b>Fett?</b> Nein, nur Text.";

Ergebnis auf der Webseite:

<b>Fett?</b> Nein, nur Text.

Der Browser zeigt die Tags genau so an, wie sie im Code stehen. Das ist besonders nützlich, wenn man sicheren Text aus Benutzereingaben anzeigen möchte.

innerHTML

Mit .innerHTML kann man den gesamten HTML-Inhalt eines Elements auslesen oder verändern. Dabei werden HTML-Tags erkannt und korrekt dargestellt.

Wann man .innerHTML verwenden sollte:

  • Wenn man HTML-Strukturen einfügen möchte (z. B. Listen, Absätze, Bilder).

  • Wenn man Inhalte mit Formatierungen benötigt.

  • Wenn man sicher ist, dass der Inhalt ungefährlich ist.

HTML:

<div id="text3">Willkommen <b>Benutzer</b>!</div>
<button id="btn3">HTML ändern</button>

JavaScript:

const div = document.querySelector("#text3");
const button3 = document.querySelector("#btn3");

button3.addEventListener("click", () => {
    div.innerHTML = "Neuer <i>HTML</i>-Inhalt mit <b>Formatierung</b>!";
});

Erklärung: Beim Klick auf den Button wird der Inhalt vollständig ersetzt. HTML-Tags werden interpretiert, sodass der Text „HTML“ kursiv und „Formatierung“ fett angezeigt wird.

Man kann mit .innerHTML auch ganze HTML-Strukturen einfügen:

div.innerHTML = "<ul><li>Apfel</li><li>Banane</li><li>Kirsche</li></ul>";

Ergebnis: eine Liste mit drei Einträgen.

Sicherheit bei innerHTML

Beim Einsatz von .innerHTML sollte man vorsichtig sein, wenn der Inhalt nicht vollständig kontrolliert wird – zum Beispiel, wenn er aus einem Formular oder einer Benutzereingabe stammt. Ein Angreifer könnte versuchen, schädlichen JavaScript-Code einzuschleusen. Dieses Problem nennt man Cross-Site Scripting (XSS).

Unsicheres Beispiel:

div.innerHTML = userInput; // userInput kommt z. B. aus einem Formular

Wenn jemand hier <script>alert('Hacked!')</script> eingibt, würde der Browser das Skript tatsächlich ausführen. Das kann zu Sicherheitslücken führen.

So lässt sich das vermeiden:

  • In solchen Fällen sollte man statt .innerHTML besser .textContent verwenden.

  • Wenn HTML unbedingt nötig ist, sollte man den Text vorher prüfen und bereinigen, bevor er eingefügt wird.
