Eventverarbeitung

Wenn eine Webseite auf Benutzeraktionen reagieren soll – also zum Beispiel auf Klicks, Tastatureingaben oder Bewegungen der Maus – dann spricht man von Eventverarbeitung (oder Ereignisverarbeitung).

Damit JavaScript auf ein Ereignis reagieren kann, muss das Ereignis mit einer Funktion verknüpft werden. Dazu verwendet man die Methode addEventListener().

Sie „lauscht“ auf ein bestimmtes Ereignis (z. B. einen Klick) und führt dann den gewünschten Code aus.

Der Aufbau sieht so aus:

element.addEventListener('eventname', function() {
  // Code, der ausgeführt wird, wenn das Event passiert
});

  • element → das HTML-Element, das reagieren soll

  • 'eventname' → der Name des Ereignisses (z. B. 'click', 'keydown', 'mouseover')

  • function() { ... } → die Funktion, die ausgeführt wird, wenn das Event eintritt

Klick-Event auf einen Button

HTML:

<button class="btn">Klick mich!</button>

JavaScript:

// Das Button-Element auswählen
const button = document.querySelector('.btn');

// Event-Listener hinzufügen
button.addEventListener('click', function() {
  // Diese Funktion wird ausgeführt, wenn du auf den Button klickst
  console.log('Du hast den Button geklickt!');
});

Erklärung: Wenn man auf den Button klickt, löst der Browser ein click-Event aus und erzeugt ein Event-Objekt mit Informationen über das Ergeignis. Der addEventListener() fängt dieses Event ab und führt die Funktion aus.

Eigenschaften Event-Objekt

Wenn man einem Event-Listener eine Funktion übergibt, kannst man einen Parameter (oft event oder e) angeben. Dieses Objekt enthält viele Informationen über das Ereignis.

button.addEventListener('click', function(event) {
  console.log('Event-Typ:', event.type);       // z. B. "click"
  console.log('Ziel des Events:', event.target); // Das Element, auf das du geklickt hast
});

Eigenschaft

Bedeutung

event.type

Welches Event ausgelöst wurde (z. B. "click")

event.target

Das Element, auf dem das Event passiert ist

event.key

Bei Tastatur-Events: welche Taste du gedrückt hast

event.clientX, event.clientY

Mausposition innerhalb des Browserfensters

event.preventDefault()

Verhindert die Standardaktion des Events

Mausbewegung auf einem Bild

HTML:

<img class="bild" src="https://picsum.photos/200" alt="Beispielbild" width="200">

JavaScript:

const bild = document.querySelector('.bild');

// Reagiere, wenn die Maus über das Bild geht
bild.addEventListener('mouseover', function() {
  console.log('Die Maus ist über dem Bild!');
});

// Reagiere, wenn die Maus das Bild wieder verlässt
bild.addEventListener('mouseout', function() {
  console.log('Die Maus hat das Bild verlassen!');
});

So kann man z. B. Bilder hervorheben oder verändern, wenn die Maus darüber fährt.

Tastendruck abfangen

HTML:

<input class="text" id="textfeld" type="text" placeholder="Tippe etwas...">

JavaScript:

const eingabe = document.querySelector('.text');

// Reagiere auf jeden Tastendruck
eingabe.addEventListener('keydown', function(event) {
  console.log('Du hast diese Taste gedrückt:', event.key);
});

event.key zeigt dir, welche Taste du gedrückt hast (z. B. „a“, „Enter“ oder „Backspace“). Damit kannst du z. B. Eingaben prüfen oder Shortcuts erstellen.

Formular absenden

HTML:

<form id="formular">
  <input type="text" placeholder="Dein Name">
  <button type="submit">Absenden</button>
</form>

JavaScript:

const form = document.querySelector('#formular');

form.addEventListener('submit', function(event) {
  // Verhindere das automatische Neuladen der Seite
  event.preventDefault();
  console.log('Du hast das Formular abgeschickt!');
});

Mit event.preventDefault() verhindert man die Standardaktion des Events (z. B. das Neuladen der Seite).

Einen Event-Listener wieder entfernen

Manchmal will man, dass ein Event nur einmal reagiert oder später deaktiviert wird. Dafür gibt es removeEventListener().

Das funktioniert nur, wenn man eine benannte Funktion verwendest (keine anonyme).

<button class="stop">Klick mich!</button>

const stopButton = document.querySelector('.stop');

function handleClick() {
  console.log('Du hast den Button geklickt!');
  stopButton.removeEventListener('click', handleClick); // Listener wird entfernt
}

stopButton.addEventListener('click', handleClick);

Jetzt reagiert der Button nur einmal auf den Klick.

Anonyme, benannte und Arrow Functions

Art der Funktion

Beispiel

Besonderheiten

Anonyme Funktion

button.addEventListener('click', function() { ... });

Schnell und direkt, kann aber nicht entfernt werden

Benannte Funktion

button.addEventListener('click', handleClick);

Kann mehrfach verwendet oder entfernt werden

Arrow Function

button.addEventListener('click', () => { ... });

Kürzere Schreibweise, erbt this aus der Umgebung
