Texte und Werte

Wenn man mit JavaScript arbeitet, möchte man häufig den Text oder den Wert eines HTML-Elements verändern – etwa eine Begrüßung, eine Nachricht oder eine Beschreibung auf der Webseite. Dafür gibt es verschiedene Eigenschaften, mit denen man Texte, HTML-Strukturen oder Werte im DOM verändern kann.

Die wichtigsten sind:

  • .textContent – wenn man nur Text (ohne HTML) einfügen oder auslesen möchte.

  • .innerHTML – wenn man HTML-Strukturen (z. B. Überschriften, Formatierungen oder Listen) mit einfügen will.

  • .value – um Werte in Formularfeldern zu lesen oder zu setzen.

  • .getAttribute() / .setAttribute() – um HTML-Attribute wie href oder src auszulesen oder zu verändern.

  • .dataset – um eigene data-* Attribute zu lesen oder zu ändern.

Alle diese Möglichkeiten helfen, Webseiten dynamisch zu gestalten, ohne die HTML-Datei selbst zu verändern.

textContent

Die Eigenschaft .textContent liest oder ändert den gesamten Text eines Elements, unabhängig davon, ob der Text sichtbar oder versteckt ist. HTML-Tags werden nicht interpretiert, sondern als einfacher Text behandelt.

Wann .textContent verwendet werden sollte:

  • Wenn man nur reinen Text einfügen möchte.

  • Wenn keine HTML-Formatierungen benötigt werden.

  • Wenn der Inhalt sicher sein soll (z. B. Texte aus Eingaben oder externen Daten).

HTML:

<p id="text2">Hallo Welt!</p>
<button id="btn2">Text ändern</button>

JavaScript:

const p2 = document.querySelector("#text2");
const button2 = document.querySelector("#btn2");

button2.addEventListener("click", () => {
    p2.textContent = "Hallo JavaScript!";
});

Erklärung: Beim Klick auf den Button wird der gesamte Inhalt des <p>-Elements ersetzt. Selbst wenn man HTML-Tags in den neuen Text schreibt, werden diese nicht als HTML erkannt, sondern als normaler Text angezeigt.

innerHTML

Mit .innerHTML kann man den gesamten HTML-Inhalt eines Elements auslesen oder verändern. Dabei werden HTML-Tags erkannt und korrekt dargestellt.

Wann .innerHTML verwendet werden sollte:

  • Wenn man HTML-Strukturen einfügen möchte (z. B. Listen, Absätze, Bilder).

  • Wenn man Inhalte mit Formatierungen benötigt.

  • Wenn man sicher ist, dass der Inhalt ungefährlich ist.

HTML:

<div id="text3">Willkommen <b>Benutzer</b>!</div>
<button id="btn3">HTML ändern</button>

JavaScript:

const div = document.querySelector("#text3");
const button3 = document.querySelector("#btn3");

button3.addEventListener("click", () => {
    div.innerHTML = "Neuer <i>HTML</i>-Inhalt mit <b>Formatierung</b>!";
});

Erklärung: Beim Klick auf den Button wird der Inhalt vollständig ersetzt. HTML-Tags werden interpretiert, sodass der Text „HTML“ kursiv und „Formatierung“ fett angezeigt wird.

Man kann mit .innerHTML auch ganze HTML-Strukturen einfügen:

div.innerHTML = "<ul><li>Apfel</li><li>Banane</li><li>Kirsche</li></ul>";

Ergebnis: eine Liste mit drei Einträgen.

Sicherheit bei innerHTML

Beim Einsatz von .innerHTML sollte man vorsichtig sein, wenn der Inhalt nicht vollständig kontrolliert wird – zum Beispiel, wenn er aus einem Formular oder einer Benutzereingabe stammt. Ein Angreifer könnte versuchen, schädlichen JavaScript-Code einzuschleusen (Cross-Site Scripting, kurz XSS).

Unsicheres Beispiel:

div.innerHTML = userInput; // userInput kommt z. B. aus einem Formular

Wenn jemand <script>alert('Hacked!')</script> eingibt, würde der Browser das Skript tatsächlich ausführen.

Sicherer:

  • Für Texteingaben besser .textContent verwenden.

  • Wenn HTML nötig ist, den Text vorher prüfen oder bereinigen.

value

Mit .value kann man den aktuellen Wert eines Eingabefeldes lesen oder ändern. Das ist besonders nützlich bei Formularen, wenn man Nutzereingaben auswerten oder vorgeben möchte.

HTML:

<input id="nameInput" type="text" value="Max">
<button id="showName">Namen anzeigen</button>
<p id="output"></p>

JavaScript:

const input = document.querySelector("#nameInput");
const output = document.querySelector("#output");
const button = document.querySelector("#showName");

button.addEventListener("click", () => {
    output.textContent = "Eingegebener Name: " + input.value;
});

Erklärung: Mit .value wird der aktuelle Text aus dem Eingabefeld gelesen und im Absatz angezeigt. Ändert man den Wert per JavaScript, ändert sich auch der angezeigte Text im Formularfeld.

Mit .value kann man nicht nur den Wert eines Formularfeldes lesen, sondern auch ändern. So lassen sich Formulare z. B. automatisch mit Standardwerten füllen oder nach einer Aktion verändern.

HTML:

<input id="username" type="text" placeholder="Benutzername eingeben">
<button id="fillName">Namen eintragen</button>
<button id="clearName">Feld leeren</button>

JavaScript:

const input = document.querySelector("#username");
const fillButton = document.querySelector("#fillName");
const clearButton = document.querySelector("#clearName");

fillButton.addEventListener("click", () => {
    input.value = "Max Mustermann";
});

clearButton.addEventListener("click", () => {
    input.value = "";
});

Erklärung:

  • Beim Klick auf „Namen eintragen“ wird der Wert des Eingabefeldes auf „Max Mustermann“ gesetzt.

  • Beim Klick auf „Feld leeren“ wird der Wert wieder entfernt.

So kann man Felder automatisch ausfüllen, z. B. mit gespeicherten Daten, Vorschlägen oder Standardwerten. .value wirkt dabei direkt auf den sichtbaren Inhalt des Eingabefelds – es ist also sowohl im HTML-Dokument als auch für den Benutzer sofort sichtbar.

getAttribute() und setAttribute()

Mit .getAttribute() kann man ein bestimmtes Attribut eines Elements auslesen, z. B. den Link eines <a>-Tags. Mit .setAttribute() kann man den Wert verändern.

HTML:

<a id="link" href="https://www.example.com">Zur Webseite</a>
<button id="changeLink">Link ändern</button>

JavaScript:

const link = document.querySelector("#link");
const button = document.querySelector("#changeLink");

button.addEventListener("click", () => {
    const aktuellerLink = link.getAttribute("href");
    console.log("Bisheriger Link:", aktuellerLink);
    link.setAttribute("href", "https://www.hs-flensburg.de");
    link.textContent = "Zur Hochschule Flensburg";
});

Erklärung: Zuerst wird der bisherige Link in der Konsole ausgegeben. Danach wird das Attribut href geändert und der angezeigte Text angepasst.

dataset

Manchmal möchte man zusätzliche Informationen zu einem Element speichern, die im HTML selbst nicht sichtbar sind. Dafür gibt es data-* Attribute, die man über .dataset ansprechen kann.

HTML:

<button id="infoButton" data-id="42" data-user="anna">Info anzeigen</button>
<p id="infoText"></p>

JavaScript:

const button = document.querySelector("#infoButton");
const text = document.querySelector("#infoText");

button.addEventListener("click", () => {
    const id = button.dataset.id;
    const user = button.dataset.user;
    text.textContent = `ID: ${id}, Benutzer: ${user}`;
});

Erklärung: Mit dataset.id und dataset.user werden die Werte aus den Attributen data-id und data-user ausgelesen. So lassen sich zusätzliche Daten direkt im HTML speichern, ohne das Layout zu beeinflussen.
